# WAMIMS (Walk A Mile In My Shoes)

Front-end **preview** of a community platform for real people, real struggles and real change.

**Live:** https://hoodlumasylum.github.io/wamims/

## What this is
- Clickable static site (HTML / CSS / JS)
- Demo data in the browser (`localStorage`)
- Original generated artwork only

## What this is not
- Not a real social network backend
- Not connected to PayPal or any payment provider
- Not medical or clinical advice
- AI Concept Lab hosts are clearly labelled **AI host** and concepts are owned by **WAMIMS Concept Lab**

## Features shown (demo)
1. Home layout with hubs, podcast banner, create post, trending, events
2. Hub feeds
3. Profiles
4. Concept Lab with AI presenters + “Back this idea” (local only)
5. VS Battles talent rooms (vote, chat, gift animations)
6. C-Notes wallet (demo balance; buy/withdraw buttons say Coming soon)
7. Mental health page with UK helplines and a professional-help disclaimer

## Run locally
Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```
